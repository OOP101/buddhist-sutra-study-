# 金刚经 · 楞严咒 学习网站

> 以敬神明 · 庄严排版 · 全文注音 · 经文详解

一个单文件佛教经典学习网站，收录 **《金刚般若波罗蜜经》全文（32品）** 与 **《大佛顶首楞严神咒》全文（五会 427 句）**，以庄严肃穆的金箔风格呈现，适合诵经、抄经与深入研读。

## 🌐 在线预览

👉 **https://oop101.github.io/buddhist-sutra-study-/**

> 若链接打不开，说明尚未开启 GitHub Pages：仓库 → **Settings → Pages** → Source 选 `Deploy from a branch` → Branch 选 `main` + `/ (root)` → Save，等待 1-2 分钟即可访问。

## ✨ 功能特性

- 📖 **经文全文** — 金刚经 32 品完整收录，楞严咒五会 + 咒心逐句排版
- 🔤 **楞严咒全文注音** — 每句咒文附拼音标注，一键开/关，不影响原文排版
- 🧭 **章节导航** — 浮动导航面板，金刚经 32 品 / 楞严咒 5 会 / 咒心一键跳转
- 📖 **经文详解** — 第三个标签页收录金刚经总论、重点品讲解、楞严咒缘起功德与修持要点
- 🛡️ **左右护法** — 手绘 SVG 韦驮菩萨（持金刚杵）与伽蓝菩萨（持青龙偃月刀）
- 🪷 **莲花纹理背景** — 纯 CSS/SVG 生成，零外链依赖，离线可用
- 🔠 **字号调节** — A- / A / A+ 三档全局缩放
- 📊 **阅读进度条** — 顶部实时显示阅读位置
- ✨ **香烟缭绕动画** — CSS 动画模拟香炉青烟，营造庄严氛围

## 📚 经文详解内容

### 金刚经
- 经名释义：金刚 · 般若 · 波罗蜜
- 核心思想：应无所住而生其心、凡所有相皆是虚妄
- 历史背景与翻译流传
- 重点品讲解：第一品（法会因由）、第三品（大乘正宗）、第四品（妙行无住）、第五品（如理实见）、第十品（庄严净土）、第十四品（离相寂灭）、第十八品（一体同观）、第二十六品（法身非相）、第三十二品（应化非真）

### 楞严咒
- 出处与缘起（阿难摩登伽女之难）
- 五会结构：毗卢遮那佛法会、释迦牟尼佛法会、观世音菩萨法会、刚藏菩萨法会、文殊师利菩萨法会
- 咒心逐句略释
- 持诵功德与注意事项

## 🚀 本地使用

直接双击打开 `buddhist-sutra.html` 即可，或部署到任意静态托管平台（GitHub Pages / Vercel / CloudStudio 等）。

```bash
# 本地预览（Python 方式）
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 🛠️ 技术栈

- 原生 HTML / CSS / JavaScript（零依赖）
- CSS 变量实现主题与字号缩放（`--font-scale` / `--pinyin-display`）
- CSS 伪元素 `attr(data-pinyin)` 实现注音叠加
- 内联 SVG 手绘护法神像与莲花纹理
- 响应式三栏布局（1200px / 768px 断点）
